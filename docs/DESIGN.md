# SteamPACC — проектный документ

Документ описывает устройство программы SteamPACC: цель, состав модулей, поток
данных, источники цен, определение активной игры, план оверлея, риски и
допущения. Актуально для этапов M1–M2.

## 1. Цель

SteamPACC — программа для Windows, которая работает в фоне и показывает
прозрачный оверлей поверх окна клиента Steam: рядом с ценой игры в регионе Steam
выводятся цены этой же игры в других валютах, которые выбрал пользователь.

Пользователь один раз калибрует положение оверлея, дальше программа сама
следит за окном Steam и пересчитывает позицию.

Польза: не нужно переключать регион Steam и покупать игру «в чужой валюте»,
чтобы сравнить цену, — достаточно посмотреть на оверлей.

## 2. Принципы и ограничения

- Инъекция DLL в Steam не используется. SteamPACC — внешняя программа.
- Только стандартная библиотека Python, PySide6 и httpx. WinAPI вызывается
  через `ctypes`, без `pywin32`.
- Файлы Steam читаются только на чтение и никогда не изменяются.
- Регион и аккаунт Steam программа не меняет.
- Весь код, интерфейс, документация и сообщения коммитов — на русском языке.
- Приложение работает молча: значок в трее, нет лишних окон поверх игр.

## 4. Состав модулей

```
src/steampacc/
├── __init__.py      — версия, общие константы
├── __main__.py      — точка входа (python -m steampacc)
├── app.py           — сборка приложения: трей, окно настроек, оверлей (M2)
├── config.py        — настройки в %APPDATA%/SteamPACC/config.json
├── currency.py      — регионы Steam, валюты, форматирование цены
├── library.py       — список игр пользователя (appinfo.vdf + appmanifest)
├── prices.py        — цены по регионам: Store API, кэш, лимиты
├── steam_paths.py   — поиск установки Steam и путей к его файлам
├── vdf.py           — парсер бинарного и текстового VDF
├── win32api.py      — обёртки WinAPI через ctypes (M2)
└── overlay.py       — прозрачное окно-оверлей (M2)
```

Поток данных сверху вниз:

```
Steam (файлы клиента) ──► vdf/steam_paths/library ──► список игр
Steam Store API     ──► prices (+ currency) ─────────► цены по валютам
Настройки            ──► config ─────────────────────► состояние оверлея
Активная игра        ──► win32api ───────────────────► что показывать
                                      оверлей (M2) ──► экран
```

## 5. Источники цен

Основной источник цен по регионам — официальный Store API Steam:

```
https://store.steampowered.com/api/appdetails?appids=<appid>&cc=<регион>&l=<язык>
```

Из ответа берётся блок `price_overview` (`currency`, `initial`, `final`,
`discount_percent`), а также `is_free` и `coming_soon`.

Важные свойства реализации:

- **Дисковое кэширование.** Ответы сохраняются в `%APPDATA%/SteamPACC/cache`
  с указанием времени запроса. Кэш живёт 24 часа, при повторном открытии той же
  игры сеть не используется.
- **Ограничение частоты.** Между запросами выдерживается пауза, чтобы не
  нагружать API Steam.
- **Суточный лимит.** Счётчик запросов в сутки; при его исчерпании программа
  берёт цены из кэша, а если кэша нет — показывает цену региона Steam.
- **Повторы.** Сетевые ошибки повторяются с нарастающей паузой (backoff).

Локальный `appcache/appinfo.vdf` — **не** источник цен по регионам: наличие
блока `regional_prices` в нём не подтверждено (поиск по открытому коду не даёт
совпадений). Из `appinfo.vdf` берём список игр, названия, `install_dir` и данные
о запуске. Если в разбираемой структуре всё же встретится блок с ценами, он
используется как необязательный быстрый путь и не является обязательным.

## 6. Определение активной игры

Для MVP определение игры не требуется: оверлей показывает цены той игры,
которая сейчас открыта в клиенте Steam на странице магазина.

Схема определения (этап M2):

1. Найти главное окно Steam по классу окна `STEAMMAINWINDOW` (`EnumWindows`).
2. Взять его прямоугольник (`GetWindowRect`) — от него считается смещение
   оверлея.
3. Если фокус на другом окне (пользователь запустил игру), оверлей прячется.
4. Если окно Steam свёрнуто (`IsIconic`) — оверлей прячется.

Привязка к конкретной игре (по appid) в MVP не делается: Steam показывает
страницу магазина внутри CEF, и надёжно вытащить оттуда appid без чтения памяти
нельзя. Направление развития — сопоставление по имени исполняемого файла
приоритетного процесса с локальной библиотекой.

## 7. План оверлея (этап M2)

Выбранный подход — **прозрачное frameless-окно с ручной калибровкой**:

- `Qt.FramelessWindowHint | Qt.WindowStaysOnTopHint`,
  `Qt.WA_TranslucentBackground`, рисование через `QPainter`.
- Позиция = `GetWindowRect(окна Steam)` + смещение X/Y из настроек.
- Поверх Steam окно удерживается периодическим `SetWindowPos` с
  `HWND_TOPMOST` и флагом `SWP_NOACTIVATE` (окно не перехватывает фокус).
- Оверлей не должен перехватывать клики: `WS_EX_TRANSPARENT | WS_EX_LAYERED |
  WS_EX_NOACTIVATE` (через `Qt.WindowTransparentForInput` и подстраховку в
  `ctypes`).
- Оверлей скрывается, если: Steam свёрнут, фокус ушёл с Steam, включилась
  полноэкранная игра, окно Steam закрыто.
- DPI: смещение пересчитывается при переносе окна Steam между мониторами с
  разным масштабом.

Распознавание текста (OCR) сознательно отложено на этап 3: оно тянет
зависимости, требует языковых моделей и хрупко к теме и масштабу интерфейса
Steam.

## 8. Настройки

`%APPDATA%/SteamPACC/config.json`:

- `currencies` — список валют для показа (например `["USD", "EUR", "RUB"]`);
- `region` — регион Steam по умолчанию (например `RU`);
- `overlay_offset_x`, `overlay_offset_y` — калибровка положения оверлея;
- `autostart` — запуск вместе с Windows;
- `show_on_focus_only` — показывать оверлей только когда Steam в фокусе.

Файл пишется атомарно (через временный файл с последующей заменой), повреждённый
файл не ломает программу: используются значения по умолчанию.

## 9. Этапы работ

- **M1 — ядро данных.** VDF, пути Steam, библиотека, цены, валюты, настройки,
  тесты парсера. Без графики.
- **M2 — оверлей и трей.** Окно-оверлей, WinAPI-обёртки, трей, окно настроек с
  выбором валют и калибровкой, определение активной игры.
- **M3 — полировка.** OCR-привязка к строке цены, автообновление, статистика
  скидок.

## 10. Риски и допущения

| Риск | Что делаем |
| --- | --- |
| Steam обновит формат `appinfo.vdf` | Парсер не падает на неизвестных полях, бинарный VDF читается по сигнатуре |
| Лимит или блокировка Store API | Кэш, backoff, суточный лимит, работа без сети |
| Оверлей перехватывает клики | `WS_EX_TRANSPARENT` и ручная проверка |
| Оверлей мешает полноэкранным играм | Скрытие по фокусу и по полноэкранному окну |
| Мониторы с разным DPI | Пересчёт смещения при `WM_DPICHANGED` |
| Валюты Steam отличаются от ISO | Таблица регионов в `currency.py`, приоритет — код из ответа API |

Допущения:

- Steam запущен на Windows 10/11 x64, клиент не запущен в режиме Family Sharing
  с ограничениями на страницу магазина.
- Цена, которую показывает Steam в интерфейсе, совпадает с ценой из
  `price_overview` ответа API для того же региона.
- Пользователь готов один раз откалибровать положение оверлея вручную.
