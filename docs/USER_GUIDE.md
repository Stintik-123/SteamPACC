# SteamPACC - руководство пользователя

SteamPACC показывает цену игры в Steam в разных валютах прямо поверх окна игры.

## Как запустить

После установки программа запускается сама и живёт в трее: значок рядом с часами
в правом нижнем углу экрана. Постоянного окна у программы нет - это нормально.

В Windows 11 новый значок может спрятаться: нажмите стрелку ^ рядом с часами,
откроется меню «скрытые значки» - значок SteamPACC лежит там.

Если значка нет в трее, запустите программу вручную:

- Пуск -> SteamPACC, или
- файл `SteamPACC.exe` в каталоге установки.

Второй запуск поверх первого не страшен: программа не даёт запуститься двум
копиям сразу.

## Как увидеть цены

1. Запустите Steam и любую установленную игру.
2. Оверлей появится в правом нижнем углу окна игры: название игры и цены
   в выбранных валютах.
3. Окно игры должно быть активным. Если игра запущена в обычном полноэкранном
   режиме, оверлей её перекрыть не сможет: переключите игру в оконный режим или
   в «полноэкранный без рамки» (в настройках Steam: Параметры -> Видео ->
   Режим отображения -> Полноэкранный без рамки).

Программа узнаёт игру по исполняемому файлу: она читает библиотеку Steam и
запоминает, какие файлы запуска у какой игры. Если игра не опознаётся,
программа пробует найти её имя в заголовке окна.

Если активно окно клиента Steam, программа показывает цены последней запущенной
игры, а при первом запуске - подсказку о том, что оверлей появится, когда будет
запущена игра.

Оверлей не перехватывает мышь: клики проходят сквозь него, играть он не мешает.

## Как поменять валюты

Нажмите правой кнопкой мыши по значку в трее -> «Настройки». Отметьте нужные
валюты, при желании поменяйте прозрачность и масштаб, нажмите «Сохранить».
Изменения применяются сразу.

## Консольные команды

Программа умеет работать и без графики - из любой консоли:

```
SteamPACC.exe games              список установленных игр
SteamPACC.exe price 570          цены игры с appid 570
SteamPACC.exe price "Dota 2"     цены игры по имени
SteamPACC.exe --selftest         отчёт о системе
```

В версии из pip команда называется `steampacc` вместо `SteamPACC.exe`.

## Если ничего не видно: диагностика

Программа пишет журнал работы. Чтобы его посмотреть:

1. Правый клик по значку в трее -> «Отчёт о системе».
2. Программа создаст отчёт и откроет папку с ним: файл `otchet.txt`
   в каталоге `%APPDATA%\SteamPACC`.
3. Пришлите этот файл - в нём видно, какие игры найдены, какие валюты
   выбраны, что делал оверлей и были ли ошибки.

Если значка в трее вообще нет, запустите в каталоге установки файл
`Диагностика.cmd` (Пуск -> SteamPACC -> Диагностика). Он запускает проверку
программы, собирает отчёт о системе и открывает его в блокноте. Пришлите
открытый файл - по нему будет видно, на каком шаге программа останавливается.

Журнал работы лежит там же: `%APPDATA%\SteamPACC\steampacc.log`.

## Частые причины, почему не видно оверлея

- Игра запущена не из Steam или не установлена в библиотеке.
- Окно игры не активно (свёрнуто) или игра в обычном полноэкранном режиме.
- В настройках сняты все валюты: если так, вернутся RUB, USD, EUR.
- Цена ещё не загрузилась: первый запрос к Steam занимает пару секунд.
- Steam API не отдал цену региона: часть регионов с некоторых IP недоступна,
  панель покажет остальные валюты.

## Автозапуск

Автозапуск включается в настройках программы (галочка «Запускать вместе
с Windows»): запись делается в реестр текущего пользователя. Отключить можно
там же или в Диспетчере задач -> вкладка «Автозагрузка» -> снять галочку
SteamPACC.

## Где лежат настройки, кэш и журнал

Всё в каталоге `%APPDATA%\SteamPACC`:

- `config.json` - валюты, прозрачность, масштаб оверлея.
- `prices.json` - кэш цен, обновляется раз в 15 минут.
- `steampacc.log` - журнал работы программы.
- `otchet.txt` - отчёт диагностики.

## Удаление

Панель управления -> Программы и компоненты -> SteamPACC -> Удалить.
