# SteamPACC - руководство пользователя

SteamPACC показывает цену игры в Steam в разных валютах прямо на страницах магазина клиентa Steam.

## Как запустить

При обычном запуске программа открывается окном: статус цен, кнопка
перезапуска Steam, галочки регионов, светлая или тёмная тема, автозапуск.
Закрытие окна сворачивает программу в трей - она продолжает работать;
полный выход - кнопка «Выход» или правый клик по значку в трее -> Выход.

В Windows 11 новый значок может спрятаться: нажмите стрелку ^ рядом с часами,
откроется меню «скрытые значки» - значок SteamPACC лежит там.

Второй запуск поверх первого не страшен: программа не даёт запуститься двум
копиям сразу.

## Как включить цены в магазине

1. Правый клик по значку в трее -> «Перезапустить Steam с ценами».
   Steam закроется и откроется снова (~20 секунд) - уже с интеграцией.
2. Откройте в магазине страницу любой игры (не обязательно установленной).
3. Под карточкой покупки появится блок «Цены в других регионах» - цены в
   выбранных регионах, со скидками.
4. У игр с дополнениями под карточкой есть строка «Цены DLC в других регионах»:
   по клику под каждым DLC появляется его цена, повторный клик сворачивает.

Блок обновляется сам при переходе между страницами игр. Выбор регионов
применяется мгновенно, без перезагрузки страниц.

## Как поменять регионы: настройки внутри Steam

Откройте настройки Steam (Steam -> Настройки). В левом меню, внизу,
есть пункт **SteamPACC**: клик по нему открывает список всех 16 регионов
с галочками прямо в окне настроек. Отметьте нужные - цены на открытых
страницах магазина обновятся сразу.

Те же галочки есть и в настройках программы: правый клик по значку
в трее -> «Настройки».

## Консольные команды

Программа умеет работать и без графики - из любой консоли:

```
SteamPACC.exe games              список установленных игр
SteamPACC.exe price 570          цены игры с appid 570
SteamPACC.exe price "Dota 2"     цены игры по имени
SteamPACC.exe --selftest         отчёт о системе
```

В версии из pip команда называется `steampacc` вместо `SteamPACC.exe`.

## Если что-то не работает: диагностика

Программа пишет журнал работы. Чтобы его посмотреть:

1. Правый клик по значку в трее -> «Отчёт о системе».
2. Программа создаст отчёт и откроет папку с ним: файл `otchet.txt`
   в каталоге `%APPDATA%\SteamPACC`.
3. Пришлите этот файл - в нём видно, что делала программа и были ли ошибки.

Если значка в трее вообще нет, запустите в каталоге установки файл
`Диагностика.cmd` (Пуск -> SteamPACC -> Диагностика). Он запускает проверку
программы, собирает отчёт о системе и открывает его в блокноте.

Журнал работы лежит там же: `%APPDATA%\SteamPACC\steampacc.log`.

## Частые вопросы

- **У региона написано «Недоступно в этом регионе».** Steam не отдаёт цену
  этого региона для данной игры (чаще всего с российских IP это юань).
  Остальные регионы работают.
- **Блок цен не появился.** Steam запущен без интеграции: нажмите в трее
  «Перезапустить Steam с ценами».
- **После обновления Steam блок пропал.** Steam поменял вёрстку страниц -
  дождитесь обновления SteamPACC.

## Автозапуск

Автозапуск включается в настройках программы (галочка «Запускать вместе
с Windows»): запись делается в реестр текущего пользователя. Отключить можно
там же или в Диспетчере задач -> вкладка «Автозагрузка» -> снять галочку
SteamPACC.

## Где лежат настройки, кэш и журнал

Всё в каталоге `%APPDATA%\SteamPACC`:

- `config.json` - регионы цен, интеграция, автозапуск.
- `prices.json` - кэш цен консольных команд, обновляется раз в 15 минут.
- `steampacc.log` - журнал работы программы.
- `otchet.txt` - отчёт диагностики.

## Удаление

Панель управления -> Программы и компоненты -> SteamPACC -> Удалить.
