# SteamPACC

**SteamPACC** (Steam Price and Currency Converter) — программа для отображения цен игр в Steam в разных валютах. Работает как нативный оверлей поверх окна Steam.

## 🎯 Возможности

✅ **Автоматическое отображение цен** — просто наведите на игру в Steam, и цены появятся
✅ **Несколько валют** — поддерживаются RUB, USD, EUR, GBP, TRY, KZT, UAH и другие
✅ **Нативный стиль Steam** — оверлей выглядит как часть клиента Steam
✅ **Кэширование цен** — цены сохраняются и работают оффлайн (на 15 минут)
✅ **Интеграция с треем** — управление программой через иконку в трее
✅ **Настройки** — выбор валют, прозрачности, масштаба
✅ **Автозапуск** — опциональный запуск вместе с Windows
✅ **Поддержка библиотеки Steam** — автоматически определяет установленные игры

## 📸 Скриншоты

Программа отображает цены в оверлее поверх окна Steam:
- При наведении на игру в библиотеке
- При просмотре страницы игры в магазине
- Поддерживает скидки и форматирование цен

## 📥 Установка

### Способ 1: Установщик (рекомендуется)

1. Скачайте последний установщик из [Releases](https://github.com/Stintik-123/SteamPACC/releases)
2. Запустите `SteamPACC-Setup-<версия>.exe`
3. Следуйте инструкциям мастера установки
4. Запустите SteamPACC из меню Пуск или с рабочего стола

### Способ 2: Портативная версия

1. Скачайте архив из [Releases](https://github.com/Stintik-123/SteamPACC/releases)
2. Распакуйте в любую папку
3. Запустите `SteamPACC.exe`

### Способ 3: Из исходников

```bash
# Клонируйте репозиторий
git clone https://github.com/Stintik-123/SteamPACC.git
cd SteamPACC

# Создайте виртуальное окружение
python -m venv .venv
.venv\Scripts\activate  # Windows
source .venv/bin/activate  # Linux/Mac

# Установите зависимости
pip install -r requirements.txt

# Соберите программу
pyinstaller --noconfirm --clean --onefile --windowed --name SteamPACC --paths src src/steampacc/__main__.py

# Готово! Исполняемый файл будет в папке dist/
```

## 🚀 Использование

1. **Запустите Steam**
2. **Запустите SteamPACC** (из меню Пуск, рабочего стола или автозагрузки)
3. **Наведите на игру** в Steam — цены появятся автоматически

### Управление

- **Иконка в трее** (рядом с часами):
  - Правый клик → "Показать оверлей" — показать цены текущей игры
  - Правый клик → "Настройки" — изменить настройки
  - Правый клик → "Выход" — закрыть программу

### Горячие клавиши

- Программа автоматически обновляет цены при смене активного окна
- Нет необходимости в ручном управлении

## ⚙️ Настройки

Настройки хранятся в файле `%APPDATA%\SteamPACC\config.json` (Windows) или `~/.config/SteamPACC/config.json` (Linux/Mac).

### Доступные параметры:

| Параметр | Тип | Описание | Значение по умолчанию |
|----------|-----|----------|---------------------|
| `currencies` | массив строк | Список отображаемых валют | `["RUB", "USD", "EUR"]` |
| `overlay_opacity` | число | Прозрачность оверлея (0.1 - 1.0) | `0.9` |
| `overlay_scale` | число | Масштаб оверлея (50 - 200) | `100` |
| `launch_with_steam` | булево | Запускать с Windows | `true` |

### Пример config.json:

```json
{
  "language": "ru",
  "country": "ru",
  "overlay_opacity": 0.95,
  "overlay_scale": 100,
  "launch_with_steam": true,
  "currencies": ["RUB", "USD", "EUR", "GBP"]
}
```

## 📊 Как это работает

1. **Обнаружение игры** — программа следит за активным окном Steam
2. **Извлечение appid** — определяет идентификатор игры из заголовка окна или библиотеки
3. **Получение цен** — запрашивает цены через Steam Store API
4. **Кэширование** — сохраняет цены для оффлайн-доступа
5. **Отображение** — показывает цены в оверлее поверх Steam
