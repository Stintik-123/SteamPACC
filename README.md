# SteamPACC

**SteamPACC** (Steam Price and Currency Converter) — программа для отображения цен игр в Steam в разных валютах. Работает как нативный оверлей поверх активного окна игры или Steam.

## Возможности

**Цены прямо в магазине Steam** — на странице любой игры блок с ценами других регионов появляется под карточкой покупки, как у Augmented Steam, но внутри клиента
**Цены поверх окна игры** — запустите игру, и в углу окна появятся её цены в выбранных валютах
**Любые игры** — не только установленные: цены определяются по открытой странице магазина
**Определение игры по процессу** — программа узнаёт игру по исполняемому файлу из библиотеки Steam, без привязки к заголовку окна
**Несколько валют** — RUB, USD, EUR, GBP, TRY, KZT, UAH и другие
**Нативный стиль Steam** — тёмная панель в стиле клиента, не перехватывает клики и фокус
**Кэширование цен** — цены сохраняются и работают оффлайн (15 минут)
**Сеть в фоне** — цены качаются в отдельном потоке, интерфейс не замирает
**Интеграция с треем** — управление через иконку в трее
**Консольный режим** — `steampacc games` и `steampacc price 570` работают без графики
**Автозапуск** — включается галочкой в настройках, пишется в реестр

## Установка

### Способ 1: Одна команда из консоли (рекомендуется)

В PowerShell:

```powershell
irm https://raw.githubusercontent.com/Stintik-123/SteamPACC/main/installer/install.ps1 | iex
```

Скрипт скачает последний релиз, установит программу в `%LOCALAPPDATA%\SteamPACC`, создаст ярлык в меню «Пуск» и предложит включить автозапуск.

### Способ 2: Установщик

1. Скачайте `SteamPACC-Setup-<версия>.exe` из [Releases](https://github.com/Stintik-123/SteamPACC/releases)
2. Запустите и следуйте инструкциям мастера

### Способ 3: Портативная версия

1. Скачайте `SteamPACC.exe` из [Releases](https://github.com/Stintik-123/SteamPACC/releases)
2. Положите в любую папку и запустите

### Способ 4: Из исходников через pip

```bash
git clone https://github.com/Stintik-123/SteamPACC.git
cd SteamPACC
pip install .
steampacc        # графический режим
steampacc games  # консольный список игр
```

Или без клона: `pip install git+https://github.com/Stintik-123/SteamPACC.git`

## Использование

1. **Запустите SteamPACC** — он появится в трее (рядом с часами)
2. **Для цен в магазине**: правый клик по значку → «Перезапустить Steam с ценами». Steam перезапустится с включённой интеграцией (~20 секунд)
3. **Откройте любую игру в магазине Steam** — под карточкой покупки появится блок «Цены в других регионах»
4. **Для цен поверх игры** — запустите любую установленную игру: панель появится в углу её окна

Блок цен обновляется сам при переходе между страницами игр. Валюты выбираются в настройках и применяются на открытых страницах сразу.

### Как это безопасно

Программа подключается к отладочному порту Steam (штатный флаг `-cef-enable-debugging`), без изменения файлов клиента и без DLL-инъекций. Внедрённый сценарий только запрашивает цены через официальный API магазина и рисует блок — он не отправляет данные наружу и не трогает аккаунт.

### Управление

Правый клик по значку в трее:

- **Перезапустить Steam с ценами** — включить интеграцию с магазином
- **Показать оверлей** — показать панель прямо сейчас
- **Настройки** — валюты, прозрачность, масштаб, интеграция, автозапуск
- **Отчёт о системе** — файл диагностики, откроется папка с ним
- **Выход**

### Консольные команды

Работают без графики — из любого терминала:

```bash
steampacc games             # список установленных игр с appid и размером
steampacc price 570         # цены Dota 2 по appid
steampacc price "Dota 2"    # цены по имени игры
steampacc --selftest        # отчёт о системе
steampacc --smoke           # проверка графической части
steampacc --version         # версия
```

В портативной версии вместо `steampacc` используйте `SteamPACC.exe games`.

## Настройки

Хранятся в `%APPDATA%\SteamPACC\config.json`:

| Параметр | Тип | Описание | По умолчанию |
|----------|-----|----------|--------------|
| `currencies` | массив строк | Валюты для показа | `["RUB", "USD", "EUR"]` |
| `overlay_opacity` | число | Прозрачность оверлея (0.3 - 1.0) | `0.9` |
| `overlay_scale` | число | Масштаб оверлея (75 - 150) | `100` |
| `launch_with_steam` | булево | Запускать с Windows | `false` |

Повреждённый файл не ломает программу: подставляются значения по умолчанию.

## Как это работает

1. **Поиск активного окна** — каждые 1,5 секунды программа смотрит, какое окно активно
2. **Определение игры** — по имени процесса (сопоставляется с файлами в каталогах библиотеки Steam), затем по заголовку окна
3. **Получение цен** — официальный Store API Steam, запросы идут в фоновом потоке
4. **Кэширование** — цены хранятся по парам «игра + валюта» 15 минут
5. **Отображение** — панель в углу активного окна, прозрачная для мыши

## Известные ограничения

- Steam Store API с некоторых IP не отдаёт цены отдельных регионов (например, RUB/EUR для части игр) — в блоке покажется прочерк, остальные валюты работают
- Интеграция с магазином требует перезапуска Steam с флагом отладки — SteamPACC делает это за вас одной кнопкой
- После обновления Steam вёрстка страниц может измениться — тогда блок цен надо будет подправить в новой версии
- В полноэкранном (exclusive) режиме игры оверлей не виден — переключите игру в «полноэкранный без рамки»
- Программа не меняет регион и файлы Steam, не внедряется в клиент через DLL

## Требования

- **Windows 10/11** (64-bit)
- **Steam** (установлен и запущен)
- **Python 3.11+** (для запуска из исходников)
